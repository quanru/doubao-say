# 豆包说 macOS 开发预览版

独立的 Swift 菜单栏应用，要求 macOS 13 及以上。界面默认英文，可选择简体中文或跟随系统。Mac 版提供与 Linux 版对应的识别服务、润色、录音手势、设置与文字恢复功能；权限、设备和输入接口使用 macOS 原生实现。逐项范围与验收边界见 [功能对照](PARITY.zh-CN.md)。尚未公开发布。

## 构建与运行

安装 Xcode Command Line Tools 或完整 Xcode 后，在仓库根目录执行：

```bash
~/.local/bin/dev-gate run --label doubao-macos-build -- bash macos/build.sh
open 'build/macos/arm64/Doubao Say.app'
```

`dev-gate` 是本开发机器的资源管理工具；其他机器直接运行 `bash macos/build.sh` 即可。脚本默认构建当前机器架构。Intel Mac 的产物在 `build/macos/x86_64/`。可设置 `DOUBAO_MAC_ARCH=x86_64` 交叉编译，但交叉编译不代表完成 Intel 运行验证。

## 首次使用与设置

1. 首次启动会打开“设置”，也可从菜单栏波形图标打开。在“识别服务”中选择豆包账号、火山引擎官方 API 或 Deepgram Nova-3（英语）。豆包使用登录窗口；官方服务填写自己的 API Key，可先测试连接。火山资源 `volc.seedasr.sauc.duration` 已内置，不需要 App ID。Deepgram 使用美式英语、标点和智能格式化。
2. 保存设置。允许麦克风访问，并从“启用全局快捷键”授予辅助功能权限。系统要求本人输入密码时在系统弹窗完成，不向应用填写系统密码。
3. 在“使用准备”中选择麦克风，先进行三秒本地检查，再进行五秒语音测试。语音测试会向已保存的识别服务发送音频，结果只显示在软件内，不粘贴，也不发送回车。全部检查完成后点击“完成设置”，后续启动不再自动打开使用准备。
4. 在目标应用的普通文本输入框中放好光标。默认 `Control+Option+空格`，可在“快捷键”中录制其他组合或单独修饰键；选键不使用麦克风。
5. 短按切换录音；按住达到默认 350 毫秒后说话，松开结束。开启“双击发送回车”时，短按需等待默认 300 毫秒确认，双击结束录音并在输入后发送回车，空闲时双击发送回车。可调整两项阈值或关闭双击。Fn 作为触发键时，其他按键也可结束当前录音。`Esc` 取消，单次最多 60 秒。

按下触发键后，先在内存保存最多三秒本地预录音，确认单击或长按后再发送到识别服务。双击或取消会丢弃尚未确认的音频。设置更改使用“保存设置”明确提交，录音和检查期间不能提交；已有网页登录、语言和自动粘贴选择保留。

“通用”中可选择麦克风、剪贴板或辅助功能直接输入、登录时启动、减少动态效果和四种波纹样式。“快捷键”还支持 Vibekey AU05 接收器的三键、两种旋转方向和旋钮按下映射；接收器支持默认关闭。登录时启动通过 macOS 登录项管理，可能需要在系统设置允许；注册失败会明确报错并回滚，不将失败显示为已保存。

## 语音润色

打开“语音润色”，填写 OpenAI 兼容的 Base URL、API Key 和模型，使用“测试接口”验证，再保存设置。默认关闭。建议使用低延迟小模型，服务商思考开关策略与 Linux 版一致；没有通用的跨服务商关闭思考参数。

中文、英文提示词分别编辑，可恢复 Linux 版相同的默认值。按转写文字的主要语言选择提示词，与界面语言无关。默认提示词修正明确口误、重复、无意义语气词和有充分上下文的近音错误，整理必要标点、段落与明确列举的列表；不回答转写中的问题，不添加事实。不额外注入 Midscene 等产品示例，也没有个人纠错记忆。

转写稳定、低于语音阈值并静音 1.2 秒后启动预润色。音量变化只暂停计时，文字变化才使旧请求失效，避免背景噪声反复发请求。结束录音后可复用同一段文字的预润色结果或仍在运行的请求；不同文字重新请求，旧返回不能上屏。

每次润色最多五秒，包含网络等待。失败、超时、空返回、截断或无效流式响应均使用 ASR 原文，部分润色结果不自动上屏。最终润色期间再次按听写快捷键可直接使用原文；`Esc` 取消整个输入。浮窗显示润色状态和流式预览，保持输入框焦点。

## 文字恢复与隐私

“最近文字”只保留一条内存文字，可编辑、复制、清除，或点击“三秒后重试”并切换到目标输入框；重试不发送回车。关闭“自动粘贴”后每次手动复制。识别或音频中断时保留部分文字，不自动输入。

输入前核对前台进程和原辅助功能输入元素，并等待快捷键修饰键松开。密码框不自动输入。输入目标变化或直接输入不可用时，文字保留在软件内。剪贴板在粘贴后延迟恢复，期间有新复制内容时不恢复；部分应用异步读取剪贴板可能晚于恢复时间。输入和回车前分别检查目标，但系统事件仍存在短暂竞争窗口，需要完全手动控制时关闭自动粘贴。

录音发送到所选识别服务，不保存本地录音文件。润色启用后，整段文字及停顿预览会发送到配置的接口；识别和模型用量由相应服务商向你的账号计费。会话和 API Key 分别保存在应用专属 macOS 钥匙串条目，登录 WebView 使用临时网站数据存储。偏好不包含凭证；可编辑的单条最近文字退出后消失，但完成的听写另存本机 30 天历史，可暂停或清空。诊断复制不包含转写、Cookie、账号或设备标识。

更新检查查询项目 GitHub 最新稳定发行版，间隔 24 小时；可手动检查并打开项目发行页，不自动下载安装，不假定 Linux 发行包包含 Mac 安装包。

## 验证与分发

```bash
~/.local/bin/dev-gate run --label doubao-macos-check -- bash macos/check.sh
~/.local/bin/dev-gate run --kind runtime --label doubao-macos-ui --max-runtime 90 -- \
  python3 macos/runtime-check.py 'build/macos/arm64/Doubao Say.app' artifacts/verification/macos/local --settings
```

自动检查使用虚构凭证、合成文字和回环 HTTP/WebSocket，不录音、不连接服务商、不发送键盘事件。覆盖录音手势、响应解析、三种 ASR 的队列和结束帧、润色流式解析、五秒回退、跳过、取消、缓存与过期请求。

隔离 UI 检查渲染真实设置窗口和非激活浮窗，逐页检查中英文，并由测试主进程捕获对应窗口；需要测试宿主已有屏幕录制权限。验证应用使用独立 Bundle ID，不读取真实登录会话。

构建脚本默认使用开发签名；设置 `DOUBAO_CODESIGN_IDENTITY` 可使用 Developer ID 签名并启用强化运行时。`macos/package-dmg.py` 使用指定的公证配置生成带“应用程序”拖拽入口的签名、公证 DMG。真实麦克风、快捷键、不同应用的粘贴、登录项、AU05 硬件、全屏/多屏和 Intel 运行需分别实机验收；编译和合成检查不替代这些结果。详见 [验收清单](ACCEPTANCE.zh-CN.md)。

上游来源和许可见根目录 `NOTICE` 及本目录 `UPSTREAM-LICENSE`。

外观设置支持合成声音预览，不使用麦克风。篮球动画根据声音包络估计节奏，静音后定格；减少动态效果时保留音量反馈。润色等待三秒后才显示快捷键跳过提示。升级时旧内置提示词会更新，自定义提示词保留。

配置窗口采用左侧导航和右侧分组表单；修改自动保存，无需单独点击保存按钮。文字输入停顿后保存，关闭窗口或开始测试前会立即保存；录音、选键或测试中暂缓生效，结束后自动应用。无效字段或系统权限问题会显示未保存提示，修正后继续自动保存。AU05 接收器关闭时隐藏映射设置，重新开启会显示原有映射。

界面支持 English、简体中文和跟随系统，可在“通用 → 界面语言”或菜单栏切换，立即生效并记住选择，无需额外确认。跟随系统按系统语言顺序选择支持的语言，均不支持时使用英语。界面语言不会改变识别引擎的语种，也不会翻译转写内容。

使用准备采用四步引导：连接识别服务 → 检查麦克风 → 启用快捷键 → 语音试说。当前步骤通过后才能进入下一步，可返回前一步调整。麦克风检查只在本机进行，语音试说调用所选识别服务且不粘贴文字。


## 个人词汇与 30 天历史

「个人词汇」每行输入一个词，自动保存，最多 200 个词，每个不超过 80 个字符。词汇会作为 AI 润色的参考；须配置并启用润色，不会训练 ASR，也不会全局替换近音词。

「输入历史」记录本应用的识别原文、最终文字、润色和输入状态。数据仅存本机，超过 30 天自动清理，不记录音频、试说测试或其他应用的键盘输入。可以暂停记录、查看原文、放回最近文字编辑，以及清空历史。

「本地词频」统计已发送的润色结果。「AI 整理高频词」仅发送候选词与次数到现有润色服务，最长等待 25 秒，不上传完整历史。AI 返回的新造词会被拒绝；选择候选后点击「添加所选词汇」才会修改词库。普通听写润色仍保持五秒截止。
