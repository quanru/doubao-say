# 真实豆包 ASR 验证

这是手动运行的联网验证，不进入 CI。使用客户端保存的豆包网页登录会话，凭证只在进程内读取，不导出。首次运行独立测试程序时，macOS 可能要求本人输入钥匙串密码。

先在应用内完成豆包登录，再编译 `LiveASRCheck.swift`，同时包含 `ASRResponse.swift`、`DoubaoASRClient.swift`、`ASRParamsStore.swift`。构建须通过本机 heavy 资源闸门。

运行程序时传入一个或多个 PCM 文件路径；格式为 16 kHz、单声道、有符号 16 位小端，每条不超过 30 秒。所有样本共用一次钥匙串读取，逐条连接真实服务。只使用专门合成的测试音频，返回的 JSON 包含测试转写文字，不含认证参数。

`PASS` 表示收到非空文字且服务完成或音频发送完成后返回文字，不代表文字完全正确。准确率需要另外将返回文字与合成原稿对比。此检查不覆盖麦克风录音、全局快捷键、目标应用粘贴，也不验证热词提升效果。
