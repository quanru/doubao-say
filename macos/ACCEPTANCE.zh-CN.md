## 录音与粘贴

在备忘录中新建一条空白测试笔记，不使用已有内容或密码输入框。

测试句：**今天用 Midscene 测试 Mac 版语音输入，第二句话检查标点。**

- [ ] 短按 Control+Option+空格开始，真实说出测试句，再短按结束。最终文字只插入一次。
- [ ] 浮窗出现期间，原文本输入框保持焦点。
- [ ] 按住快捷键超过 300 毫秒说话，松开后结束并只粘贴一次。
- [ ] 开始说话后按 Esc 取消，浮窗消失，笔记没有新增文字。
- [ ] 连续录入三次，结果不串到其他会话，不重复插入。
- [ ] 录音期间切换到另一个输入框或应用，结束后不自动粘贴；可从菜单复制最近结果。
- [ ] 关闭自动粘贴后录入，笔记不自动增加文字，菜单可复制最近结果。

## 剪贴板与应用兼容

先复制合成文字 `clipboard-before-doubao-check`，完成自动粘贴后等待至少一秒，在另一个空白测试位置手动粘贴，应得到原剪贴板文字。

- [ ] 自动粘贴后恢复原剪贴板。
- [ ] 自动粘贴后立即复制新内容，新内容不会被原剪贴板覆盖。

- [x] 退出后重新启动，登录状态仍可用；最近结果不保留。
