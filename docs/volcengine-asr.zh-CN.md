# 豆包与火山引擎官方语音识别

豆包说提供两种云端语音识别方式。两者都不是本地离线模型，录音时都会把音频发送给对应的服务商，但账号、鉴权和计费方式不同。

| 方式 | 需要什么 | 费用与稳定性 | 适合谁 |
| --- | --- | --- | --- |
| 豆包网页登录（默认） | 豆包账号和网页会话 | 无需单独购买火山引擎 API；依赖豆包网页协议，可能随网站变更 | 希望快速开始、不想管理云 API 的个人用户 |
| 火山引擎官方 API | 火山引擎账号、已开通的流式语音识别 2.0、API Key | 按火山引擎账号的试用额度、资源包或后付费规则计费；接口和鉴权由官方提供 | 需要正式 API、实时增量文字和独立用量管理的用户 |

无论选择哪一种方式，最终文本仍只在录音结束后一次粘贴到目标应用；“实时”指录音悬浮窗会边说边显示增量识别文字。

## 使用豆包网页登录

1. 打开豆包说，在“语音识别”步骤保留“豆包账号”。
2. 点击登录，在应用打开的网页窗口中完成豆包登录。
3. 返回豆包说，完成麦克风检测和“试说一句”。
4. 设置触发键并完成设置。

登录凭证保存在本机。该方式使用豆包网页服务，不需要火山引擎控制台、API Key 或单独充值。它是非官方网页协议接入，豆包网站的登录或协议变化可能影响可用性。

## 开通火山引擎双向流式语音识别 2.0

以下步骤适用于火山引擎**新版豆包语音控制台**。不要使用旧版文档中的 App ID、Access Token 或应用列表来配置豆包说。

1. 登录[火山引擎控制台](https://console.volcengine.com/)，按控制台要求完成账号认证。
2. 进入[新版豆包语音控制台](https://console.volcengine.com/speech/new/setting/activate)。
3. 在页面顶部选择项目，例如 `default（默认项目）`。服务和 API Key 必须属于同一个项目；不同项目的资源相互隔离。
4. 打开左侧的“开通管理”，在“大模型”中找到“流式语音识别 2.0”。
5. 点击开通、增购或按控制台提示确认计费协议，直到服务显示“已开通”。页面会显示剩余试用或已购音频处理时长；具体额度、有效期和价格以你的控制台为准。
6. 打开左侧的“API Key”，在同一项目下创建或复制一个 API Key。API Key 是长期凭证，不要发到 Issue、聊天、日志或截图中。

火山引擎把双向流式模式定义为“边说话边出文字”。豆包说使用 Seed ASR 2.0 小时版资源，当前双向模式主要支持中文和英文。其他语种或更完整的方言覆盖不能假定可用，请以火山引擎最新说明为准。

官方参考：

- [大模型流式语音识别产品说明](https://www.volcengine.com/docs/6561/1354871?lang=zh)
- [双向流式语音识别 WebSocket](https://docs.volcengine.com/docs/6561/2630027?lang=zh)

## 在豆包说中配置

1. 在首次设置的“登录”页直接把“语音识别服务”切换为“火山引擎官方 API”；也可以稍后在“设置 → 语音识别服务”中切换。两处会立即保存并保持同步。
2. 点击“打开语音识别设置”。
3. 粘贴刚才创建的 API Key。修改会自动保存，不需要额外点击保存。
4. 点击“测试 API Key”。看到“API Key 可用”只代表鉴权和服务权限正常，不会上传录音。
5. 回到引导页执行“试说一句”。说话过程中应在悬浮窗看到增量文字，结束后得到最终结果。

豆包说会在内部使用以下官方参数，普通用户不需要手工填写：

```text
WebSocket:    wss://openspeech.bytedance.com/api/v3/sauc/bigmodel
Resource ID: volc.seedasr.sauc.duration
Auth header: X-Api-Key
Audio:       16 kHz / 16-bit / mono PCM
```

API Key 保存在 `~/.config/doubao-say/volcengine_api_key`，文件权限仅允许当前用户读取。切回豆包网页登录不会删除 Key；使用“清除 API Key”才会删除它。

## 验证与排障

- **HTTP 401 / API Key 被拒绝**：确认 Key 来自新版豆包语音控制台，Key 所属项目与开通服务的项目一致，并确认“流式语音识别 2.0”已开通。刚开通或刚创建的 Key 也可能需要短暂等待生效。
- **测试 Key 成功，但没有文字**：检查麦克风选择并运行三秒麦克风检测；该检测只在本机执行。随后再运行真实的“试说一句”。
- **结束后有文字，但录音期间没有增量文字**：确认使用的是包含双向接口的当前版本；接口路径应为 `bigmodel`，而不是 `bigmodel_nostream`。
- **偶发空结果**：说话时间过短、输入设备错误或音量过低都可能导致空结果。先持续说一个完整短句再测试。
- **担心费用**：在新版控制台的“用量统计”或费用中心查看消耗、剩余额度和欠费状态。豆包说不会替你购买资源或充值。

不要把 VM 磁盘、配置目录、API Key 或包含私人转写内容的完整日志上传到公开 Issue。反馈问题时可提供错误时间、HTTP 状态码和火山引擎返回的 Log ID。
